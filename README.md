# 登壇諾否マイページ 共通管理版 v3.2

## v3.2 の変更点
- 管理画面「学会管理」→「学会設定」に「この学会を削除」を追加しました。
- 削除時は学会コードの再入力が必要です。
- 削除すると、その学会に紐づく先生情報・依頼・回答も削除されます。
- 日本語を含む管理者パスワードにも対応済みです。

## 更新方法
GitHub の同じリポジトリに `app.py`、`requirements.txt`、`README.md` を上書きアップロードして Commit changes してください。


## v3.3 変更点
- 先生別URLのドメインを `st.context.url` から自動取得。公開URLの手入力は原則不要。
- `YESNO_BASE_URL` は任意の上書き設定としてのみ利用。未設定でも動作。
- 「先生別URL」画面からExcel一括ダウンロードを追加。
  - 全員
  - 未回答あり
  - 追加依頼あり（初回登録済みで未回答依頼がある先生）
- URL一覧Excelには依頼件数、回答済み件数、未回答件数を収録。
