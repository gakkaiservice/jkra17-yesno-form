# JKRA17 諾否マイページ FormMailer仕様版 v2.2

第17回日本腎臓リハビリテーション学会学術集会の指定演題諾否フォーム試作版です。

## v2.2 の変更点
- 旧 Form Mailer の初回項目に合わせて、以下を追加しました。
  - ふりがな
  - 会員・非会員
  - 当日の緊急連絡先（携帯電話番号）
- 初回回答では、氏名・ふりがな・メール・会員区分・諾否・修正依頼・緊急連絡先・招聘状・備考を登録できます。
- 1件でも「承諾する」がある場合だけ、招聘状の質問を表示します。
- 招聘状が「必要」のときだけ、所属長情報・指定様式/web申請・ファイルアップロードを表示します。
- 2回目以降は、諾否と備考だけ入力可能です。
- 初回登録情報は2回目以降も表示されますが、編集できません。
- 旧 Form Mailer 回答済みの先生は、Excel取込時に初回登録済みとして引き継ぎます。
- 既存のAD列「諾／否」は回答済みとして固定し、追加依頼だけ回答できます。

## 起動方法
PowerShellでこのフォルダを開き、以下を実行します。

```powershell
py -m streamlit run app.py
```

通常画面:
http://localhost:8501

管理画面:
http://localhost:8501/?admin=1

試作版管理者パスワード:
`jkra17-demo`

## 注意
- 現在はローカルPC用の試作版です。`localhost` のURLは外部の先生からは開けません。
- メール送信機能はまだ入っていません。
- 本番運用では外部公開用サーバー、永続データ保存、管理者パスワード・トークン秘密鍵の変更が必要です。
