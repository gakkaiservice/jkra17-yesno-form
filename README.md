# 登壇諾否マイページ 共通管理版 v3.7

## v3.7 の主な変更
- 回答者への自動返信メールは常時送信します。
- 運営事務局には、回答者へ送るものと同一のメールを CC で送信します。
- 学会ごとのメール設定は主に以下です。
  - 学会名
  - 運営事務局メールアドレス（Reply-To / CC先）
  - 差出人表示名
  - 自動返信メール件名
  - 回答内容より前に表示する案内文
- 差込タグの入力は不要です。
- 氏名、学会名、今回の諾否、辞退理由、備考、初回登録情報、回答日時、マイページURLはシステムが自動でメール本文へ追加します。
- 2回目以降も、今回回答した依頼内容と備考を自動反映します。

## 更新方法
GitHub の同じリポジトリへ `app.py`、`requirements.txt`、`README.md` を上書きアップロードし、Commit changes してください。
Streamlit Community Cloud が自動で再デプロイします。

## メール送信について
Streamlit Secrets の SMTP 設定はこれまでどおり必要です。これはシステム全体で一度設定します。
