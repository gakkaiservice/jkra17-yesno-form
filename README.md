# 登壇諾否マイページ 共通管理版 v4.1.3（高速キャッシュ版）

Supabase / PostgreSQL を永続保存先として使いつつ、通常の画面表示ではDBへの往復を最小限にする高速化版です。

## 今回の速度改善
- PostgreSQLの接続プールをStreamlit再実行間で再利用します。
- 起動時のCREATE TABLE / ALTER TABLE確認はプロセスごとに原則1回だけ実行します。
- 先生用ページは「依頼一覧＋プロフィール」を1接続でまとめて取得し、そのブラウザセッション内でキャッシュします。
- 管理画面の回答一覧・先生別URL一覧も短時間キャッシュします。
- 先生別URL用Excelや回答一覧Excelは、画面を開いただけでは作りません。「Excel出力を準備」を押した時だけ生成します。
- 「最新データを再読み込み」ボタンを追加しました。通常はキャッシュ表示、必要な時だけDBから再取得します。
- 先生用フォームの「依頼状況」は表示しません。

## 更新方法
GitHub上の `app.py`、`requirements.txt`、`README.md` をこの版で上書きして Commit changes してください。

## Secrets
v4.1.2ですでにSupabaseとGmailが動いている場合、Secretsは変更不要です。
`DATABASE_URL` とSMTP設定をそのまま使用します。

## データ保存
回答・学会設定・先生情報・依頼情報・アップロードファイルの正本はPostgreSQLです。
キャッシュは表示高速化のためだけに使い、保存時には必ずPostgreSQLへ書き込みます。
