# v4.1.4 表示ロジック復元版

- 先生側の表示ロジックは v4.1.2 に戻しています。
- 今回回答が必要な未回答依頼だけを「今回ご回答いただくご依頼」に表示します。
- 回答済み依頼は下部の履歴にのみ表示します。
- 先生フォーム・先生別URLのデータ自体はキャッシュしません。
- PostgreSQL/Supabase の接続エンジンだけ再利用して、表示内容に影響しない範囲で軽量化しています。
- 「依頼状況」は先生フォーム・回答一覧には表示しません。

# 登壇諾否マイページ 共通管理版 v4.1.4

v4.1 の PostgreSQL/Supabase 永続保存版を、外部DB向けに速度改善した修正版です。

## v4.1.4 の修正
- Excel取込を1件ずつDB往復する方式から一括登録に変更
- 先生別URL画面のプロフィール取得を1人ずつ行わず一括取得に変更
- Excel取込中はスピナーを表示し、完了件数を画面に残す
- 既存の機能・DB構造・Secrets（DATABASE_URL等）は変更なし

GitHubには `app.py` / `requirements.txt` / `README.md` を上書きしてください。


## v4.1.4 速度改善
- 管理画面は選択中の画面だけ処理する方式へ変更しました。
- 先生別URL一覧はDB側で一括集計し、PostgreSQLへの往復を大幅に削減しました。
- 先生用フォーム・回答一覧・回答Excelから「依頼状況」を削除しました。
- バックアップは「準備」ボタンを押した時だけ生成します。
