# 登壇諾否マイページ 共通管理版 v4.1.3

## 変更点
- Excelに「依頼送付」「依頼送信」「依頼状況」「送信状況」のいずれかの列がある場合、値が入っている依頼だけをフォーム・先生別URL・集計の対象として取り込みます。
- 「依頼送付」列を自動認識するようにしました。
- v4.1.2のPostgreSQL高速化と「依頼状況をフォームに表示しない」仕様を引き継いでいます。

## 更新後
同じExcelをもう一度取り込んでください。空欄の「依頼送付」に該当する既存依頼は、再取込時に公開対象から外れます。

GitHubへ app.py / requirements.txt / README.md を上書きして Commit changes 後、Streamlitの公開画面を再読み込みしてください。
